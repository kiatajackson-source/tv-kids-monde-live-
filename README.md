# TV KIDS MONDE LIVE

Application Android de télévision destinée aux enfants.

## Fonctionnalités prévues

- Interface bleu ciel
- Chaînes pour enfants
- Dessins animés et musique
- Lecteur vidéo intégré
- Favoris
- Langues française et anglaise
- Contrôle parental
- Service en ligne

Les vidéos seront diffusées uniquement lorsque leur retransmission est autorisée.
